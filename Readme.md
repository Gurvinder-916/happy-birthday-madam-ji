# Happy Birthday Prativha Ji ❤️

A cinematic, interactive birthday website built with HTML, CSS, and JavaScript.

## How to Customize

1. **Add Your Photos:**
   * Go to the `images/` folder.
   * Add 10 photos of you and Prativha Ji.
   * Name them strictly as `photo1.jpg`, `photo2.jpg`, all the way to `photo10.jpg`. *(If you don't have 10 photos, the website will automatically load beautiful romantic placeholder images instead).*

2. **Add Background Music:**
   * Find a romantic birthday song you like.
   * Save it in the `music/` folder.
   * Name the file exactly `birthday.mp3`.

3. **How to Run on Your Computer:**
   * Simply double-click the `index.html` file to open it in Chrome, Safari, or Edge.

## How to Host for Free (GitHub Pages)

1. Create a free account on [GitHub](https://github.com/).
2. Create a new repository named `happy-birthday-prativha`.
3. Upload all the files (`index.html`, `style.css`, `script.js`, and the `images` & `music` folders).
4. Go to the repository **Settings** > **Pages**.
5. Under "Branch", select `main` (or `master`) and click **Save**.
6. Wait 1-2 minutes, and GitHub will give you a live URL link that you can send to Prativha Ji on WhatsApp!
